# 🔬 مختبر SQL البصري (Visual SQL Lab)

![لقطة الشاشة](https://via.placeholder.com/800x400?text=Visual+SQL+Lab)

**أداة تعليمية تفاعلية** لتعلم SQL من خلال التصور الحي لشجرة تنفيذ الاستعلامات.

## ✨ الميزات الرئيسية

- 📝 **محرر SQL متكامل** (Monaco Editor - مثل VS Code)
- 🌳 **شجرة تنفيذ بصرية** تشرح كيفية عمل استعلامك خطوة بخطوة
- 📂 **رفع ملفات CSV** وتحويلها تلقائياً إلى جداول قابلة للاستعلام
- 💾 **تصدير واستيراد** قاعدة البيانات بصيغة JSON
- 📜 **سجل الاستعلامات** للرجوع السريع
- 📚 **مكتبة أمثلة جاهزة** للتعلم
- ⚡ **قياس زمن التنفيذ** وعدد الصفوف

## 🛠️ التقنيات المستخدمة

- **Vue 3** (Composition API)
- **Vite** (بيئة التطوير)
- **AlaSQL** (محرك SQL في المتصفح)
- **D3.js** (رسم الأشجار البيانية)
- **Monaco Editor** (محرر الأكواد)
